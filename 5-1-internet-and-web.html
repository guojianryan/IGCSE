5.1.1

The Internet is not the Web

Cambridge tests this distinction directly. Marks are lost when the answer talks about Wi-Fi versus computers, instead of infrastructure versus content.

The Internet

  • A global network of interconnected computer networks.
  • Hardware: fibre-optic and copper cables, routers, switches, satellites and servers.
  • It runs on foundational protocols such as TCP/IP.
  • Analogy: the roads, tracks and bridges.

The World Wide Web

  • A collection of websites, web pages and multimedia.
  • Resources: HTML files, CSS, images and other media.
  • It is accessed over the Internet using HTTP and HTTPS.
  • Analogy: the traffic carrying people and cargo.
Exam watch · 2 marks

A difference question wants infrastructure versus service. This answer would not score: “the Web is on computers and the Internet is on Wi-Fi.” Wi-Fi is only one way a device joins the Internet.

5.1.2

Three parts of a URL

A Uniform Resource Locator is a text address for one web resource. People use it so they do not have to remember a numerical IP address.

1. Protocol

https:// The rules the browser and the server follow. HTTPS tells you the transfer will be encrypted.

2. Domain name

www.cambridgeinternational.org The readable name of the host that stores the site.

3. File path

/programmes/igcse/index.html The folder and file requested on that server.

5.1.3

HTTP asks. HTTPS hides the reply.

Hypertext Transfer Protocol is a request-response conversation between the browser and a web server. It moves text, images, sound and video. HTTPS is that same conversation with SSL/TLS encryption.

HTTP

  • Rules for transmitting web resources across the Web.
  • The browser sends a request. The server sends a response.
  • Data travels as plaintext, so it can be read if someone intercepts it.

HTTPS

  • Protects the transfer against eavesdropping and tampering.
  • SSL/TLS scrambles the data. Intercepted packets are not readable.
  • Used for banking, checkout pages, login forms and cloud storage.
Do not over-claim

HTTPS does not mean a site is honest or free of malware. It means the data between the browser and that server is encrypted and the server is authenticated. A criminal site can still have a padlock.

The browser renders the page

          
A web browser is client software. It requests files from a web server and turns HTML into the page on screen. It reads HTML, CSS and, on modern pages, JavaScript, then draws the layout, type, controls and media.

The field where the user types a URL or a search.

          

          

            
2. Navigation

            
Back, forward, and refresh, reload or stop.

          

          

            
3. Bookmarks

            
Saved shortcuts to URLs the user wants again.

          

          

            
4. History

            
A dated list of URLs already visited.

          

          

            
5. Tabs

            
Several pages open in one window.

5.1.5 continued

          
DNS is a phone directory, not the website

          
Routers use numerical IP addresses such as 198.51.100.42. People remember names such as cambridgeinternational.org. The Domain Name Server translates the name into the number.

        

        

          

            
What DNS does

            
It receives a domain name, searches its database, and returns the matching IP address so the browser can contact the right server.

          

          

            
What DNS does not do

            
It does not store the HTML, the images or the rest of the page. After the IP address comes back, the browser still has to request the files from the web server.

5.1.6

          
Cookies remember what HTTP forgets

          
A cookie is a small text file the browser stores because a web server asked it to. HTTP itself is stateless: each request arrives with no memory. Cookies carry a little state, such as a login or a basket.

        

        

          

            
What cookies are used for

            
    
              
  • Keeping someone logged in as they move between pages.
    • 
              
  • Holding the items in a shopping cart.
    • 
              
  • Storing preferences such as language or a chosen theme.
    • 
              
  • Recording browsing patterns for analytics and adverts.
    • 
            

          

          

            
Two lifetimes

            
    
              
  • Session: kept in RAM, deleted when the browser closes. Used for a live cart or a login that lasts one visit.
    • 
              
  • Persistent: kept on secondary storage (HDD or SSD) until an expiry date or until the user deletes it. Used for “remember me” and saved preferences.
    • 
            

          

        

        

          
Close the browser and see what survives

          
Set a few cookies, then close the browser. Only the persistent cookies should remain.
